# Recorder 🎥

A lightweight Minecraft-focused screen recorder for Windows, designed around older Intel integrated graphics and low-memory PCs.

## Low-end target

The default profile is intentionally conservative:

- 1280×720 target
- 30 FPS
- H.264
- Intel Quick Sync preferred
- Desktop Duplication capture through FFmpeg `ddagrab`
- No audio processing in the default path
- No preview window while recording
- FFmpeg runs below normal priority
- CPU fallback is limited to two encoding threads

The project is aimed at systems such as a Pentium-class CPU with 8 GB RAM and Intel HD/UHD integrated graphics. Actual FPS impact depends on the Minecraft version, renderer, driver, resolution, and whether the installed FFmpeg build exposes the Intel hardware encoder.

## Features

- Automatic Minecraft window detection
- F8 global start/stop hotkey
- 720p low-end recording profile
- 30/60 FPS selection
- Quality presets
- Optional cursor capture
- Intel Quick Sync H.264 when available
- CPU H.264 fallback
- Clean FFmpeg shutdown for finalized MP4 files
- Recordings saved to `Documents\\Recorder`
- Portable Windows package generated by GitHub Actions

## Why Desktop Duplication?

The recorder uses FFmpeg's `ddagrab` path instead of repeatedly copying screenshots through GDI. `ddagrab` uses the Windows Desktop Duplication API and exposes D3D11 hardware frames, allowing the preferred encoder path to stay on the GPU. This is particularly useful for keeping CPU work away from a low-end Pentium system.

## Build

Requirements for local development:

- Windows 10/11 x64
- Visual Studio 2022 with Desktop C++ workload
- Windows 10/11 SDK
- CMake 3.20+
- `ffmpeg.exe` beside `Recorder.exe` when running locally

GitHub Actions builds a portable x64 package containing both `Recorder.exe` and FFmpeg.

## Important

This is optimized for the requested low-end target, but no recorder can guarantee a fixed FPS loss on every Pentium/Intel HD 620 system. The first real benchmark should be done on the target PC and then tuned from measured Minecraft FPS, encoder load, and dropped frames.
